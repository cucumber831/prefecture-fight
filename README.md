# 都道府県ファイト

都道府県そのものが戦う、1対1の対戦ゲームです。大きさと形で、体力・威力・攻撃の速さ・足の速さが変わります。
CPUと対戦するか、友達とオンラインで対戦できます。

**遊ぶ:** https://cucumber831.github.io/prefecture-fight/

## 操作
- スマホ: 画面の左側を触るとスティックが出ます。左右にずらして移動、相手から離れる向きで防御。右下のボタンで攻撃。
- PC: A/← と D/→ で移動、Space/J で攻撃。

## 友達と対戦(オンライン)
1. 「友達(オンライン)」を選ぶ。
2. 片方が「部屋を作る」→ 出てきた6文字のコードを友達に教える。
3. もう片方がコードを入れて「部屋に入る」→ 部屋を作った人が「入れる」を押す。
4. それぞれ自分の県を選び、部屋を作った人が「たたかう」。

### 気をつけること
- 部屋コードは、対戦したい友達にだけ教えてください。
- オンライン対戦はブラウザどうしを直接つなぎます(WebRTC)。つながると、お互いのIPアドレスが相手に伝わります。つなぐための窓口として、PeerJS の無料サーバー(0.peerjs.com)を使います。
- 学校や会社のネットワークでは、つながらないことがあります。

## しくみ・安全のための作り
- サーバーを持たない静的なページです。パスワードや鍵などの秘密は入っていません。データの保存や Cookie もありません。
- 外部の部品は通信用の PeerJS 1.5.4 だけで、`vendor/` に同梱しています(MIT ライセンス、`vendor/PEERJS-LICENSE`)。
- Content-Security-Policy で、実行できるスクリプトをこのサイトのものだけに、通信先を PeerJS の窓口だけに制限しています。
- 相手から届くデータは、決まった形・範囲のもの以外は捨て、画面には文字としてだけ表示します。部屋に入れるのは1人だけで、部屋を作った人の承認が必要です。
- 試合の計算は部屋を作った人のブラウザで行い、入った人は操作だけを送ります。

都道府県の形は [dataofjapan/land](https://github.com/dataofjapan/land) のデータをもとに、各県のいちばん大きい島の輪郭を使っています。面積は国土地理院の公表値です。
